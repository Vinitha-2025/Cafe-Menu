## ☕ Modern Cafe Menu

A simple and responsive **Cafe Menu webpage** built using **HTML and CSS**.  
This project displays different categories of menu items including Coffee & Tea, Cold Beverages, and Pastries with prices.

## 📌 Purpose
This project was built to improve my understanding of:
- HTML structure
- CSS styling and positioning
- Using background images
- Designing simple webpage layouts
- Organizing content effectively

## ✨ Features
- Coffee-themed background
- Categorized menu sections
- Price listing for items

## 🛠️ Technologies Used
- HTML5
- CSS3
